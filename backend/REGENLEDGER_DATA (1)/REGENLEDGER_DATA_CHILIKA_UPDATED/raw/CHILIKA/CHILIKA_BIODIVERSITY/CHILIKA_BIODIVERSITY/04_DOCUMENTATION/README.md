- **VERIFIED_OFFICIAL** – direct from CDA public pages or official PCCF/Forest Dept publications
- **VERIFIED_HISTORICAL** – official but older observation
- **SUPERSEDED** – earlier provisional figure replaced by primary census
- **DATA_GAP** – not published on official sources accessed
